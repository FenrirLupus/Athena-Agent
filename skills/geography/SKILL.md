# Geography

The built-in geography tools:

- `geolocate` — resolve an IP (or the host machine) to a location
- `timezone` — timezone-aware current time
- `geo_distance` — distance between two lat/lon points

```json
{}
{"timezone": "America/New_York"}
{"lat1": 33.83, "lon1": -84.38, "lat2": 40.71, "lon2": -74.01}
```

Use for geographic location, timezone-aware time, and distances.
