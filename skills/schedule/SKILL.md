# Schedule

Two built-in tools:

- `schedule` — list scheduled reminders.
- `schedule_set` — set a reminder (`time`, `task`, optional `repeat`).

```json
{"time": "09:00", "task": "Morning check", "repeat": "daily"}
```

Use them when the operator asks to be reminded or wants their schedule.
