# Athena

Athena's own map: the tool/skill inventory the system injects into the
prompt. Start HERE when using Athena's tools — know what's around
before you act.

## The map (organized by purpose)

- **clock/calendar/schedule** — time, planning, reminders
- **calculator** — math, chemistry, unit conversion
- **notepad/checklist** — notes, sequenced work, flat tasks
- **syntax/geography/weather** — validation, location, environment
- **computer/screenshot/browser** — desktop control, capture, web
- **mcp/github/huggingface** — external integrations
- **system** — machine health + the CORE systems (memory, emotion,
  vault, session, kanban) + doctor/custodian/nurse/janitor
- **media/archive/network/search/clipboard/notification** — files,
  compression, connections, web search, clipboard, alerts

## How to navigate

1. Know the families above (they mirror the tools in your prompt).
2. Pick the family whose purpose matches the task.
3. Use the tool; when unsure, consult the family's TOOL.md / skill.

Start with the map, then go where the task leads.
