# Athena — Python requirements (the Operator's portability spec, 08-12).
#
# Athena's THIRD-PARTY dependency footprint is deliberately tiny:
#   fastapi        — the WEBGUI server
#   uvicorn        — the ASGI server runner (what serves the GUI)
#   pydantic       — fastapi's model layer
#   pyyaml         — config.yaml parsing
#   rich           — the CLI banner rendering
#   prompt-toolkit — the CLI REPL + the checkbox multi-select dialogs
#   huggingface-hub — the voice system's model source (the Operator's 3
#                     HuggingFace models for voice)
#
# EVERYTHING ELSE is the Python standard library (sqlite3, http,
# urllib, json, pathlib, ...) or Athena's own modules. No node, no
# github SDK — those are either provider names in the catalog or
# shell-outs to system binaries (git).
#
# Athena runs on HER OWN environment — .athena/.venv built from the
# SYSTEM python (never a shared runtime). Install:
#   /usr/bin/python3 -m venv /path/to/.athena/.venv
#   /path/to/.athena/.venv/bin/pip install -r requirements.txt
#
# The .venv + requirements.txt are WIPE-TEST KEEP ITEMS (the Operator's
# 08-12 spec) — the globally-used python environment stays with the
# house.
